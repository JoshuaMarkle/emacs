* Eigenvalues
An eigenvector of A is a nonzero vector v where
\[ A\mathbf{v} = \lambda\mathbf{v} \]
** Finding them
1. Solve $\det(A - \lambda I) = 0$ for each $\lambda$
2. Find the null space of $A - \lambda I$
** Check it numerically
#+begin_src python
import numpy as np
A = np.array([[2, 1], [0, 3]])
vals, vecs = np.linalg.eig(A)
#+end_src
** Results
| λ | eigenvector |
|---+-------------|
| 2 | (1, 0) |
| 3 | (1, 1) |
* Diagonalization :exam:
With n independent eigenvectors, $A = PDP^{-1}$.
